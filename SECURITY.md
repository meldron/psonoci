# Security Policy

## Supported Versions

Only the latest stable minor series receives security updates. After 0.7.0 is
released, the supported versions are:

| Version | Supported |
| ------- | --------- |
| 0.7.x   | ✔️        |
| < 0.7.0 | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability in `psonoci` please contact psonoci@dfjk.eu before creating a public issue.
